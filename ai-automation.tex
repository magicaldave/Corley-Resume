\section{Selected Engineering Work}

\entry{Rook}{permission-gated AI engineering agent for chat and code review}{Independent \textperiodcentered{} proprietary \textperiodcentered{} 2026}
\entrymeta{DreamWeave. Private source; releases 0.1.0 to 0.3.2 tagged; in use on the DreamWeave-MP Discord. Written in Luau on my own runtime, Jess.}
\begin{bullets}
  \item Designed an LLM-backed service that answers engineering questions in Discord and reads and reviews pull requests, issues and CI on GitHub, as a native Luau application with no Python or Node agent framework.
  \item Put authorization in code, not in the prompt: every outbound action is checked against a human-reviewed, version-controlled grant ledger, reread before each decision. A malformed grant is ignored and reported, never widened, and nothing the agent reads at runtime can add one.
  \item Made failure safe: an instruction profile that no longer matches the SHA-256 of its reviewed sources stops startup, and an ambiguous GitHub write (timeout, 5xx, crash) blocks any repeat until an operator reconciles it.
  \item Added per-reply receipts (latency, tokens, estimated cost), daily budgets and an emergency stop. Tested offline against a mock model that obeys every injected instruction: 83 cases, run from source and from the packed artifact.
  \item \verify{Specified and checked AI-assisted implementation against written requirements and acceptance tests.}
\end{bullets}

\entrymeta{\href{https://github.com/DreamWeave-MP/StroggForge}{github.com/DreamWeave-MP/StroggForge} \textperiodcentered{} GitHub Actions, Bash}
\begin{bullets}
