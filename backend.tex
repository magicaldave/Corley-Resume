\section{Selected Engineering Work}

\entry{Rook}{integration service for Discord and GitHub, in Luau}{Independent \textperiodcentered{} proprietary \textperiodcentered{} 2026}
\entrymeta{DreamWeave. Private source; releases 0.1.0 to 0.3.2 tagged; in use on the DreamWeave-MP Discord. Runs on my own runtime, Jess.}
\begin{bullets}
  \item Built a service that answers engineering questions in Discord and reads and reviews GitHub pull requests, issues and CI, calling an LLM API with tool use.
  \item Enforced authorization in code: every outbound action is checked against a version-controlled grant ledger, reread before each decision. A malformed grant is ignored and reported, never widened.
  \item Made writes safe to retry: an ambiguous GitHub write (timeout, 5xx, crash) is recorded as a durable intent and blocks any repeat until an operator reconciles it. Added per-request receipts, daily budgets and an emergency stop; 83 offline failure tests against a mock model.
\end{bullets}

\entrymeta{\href{https://github.com/DreamWeave-MP/jess}{github.com/DreamWeave-MP/jess} \textperiodcentered{} \href{https://crates.io/crates/jess}{crates.io/crates/jess} \textperiodcentered{} MIT or Apache-2.0 \textperiodcentered{} v0.1.0 (21 Oct 2026) to v0.3.0 (5 Nov 2026)}
\begin{bullets}
